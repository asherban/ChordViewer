# ADR 0013: Keep short, linked, immutable architecture decisions

Decided: 2026-10-15. Recorded: 2026-10-15.

**Decision:** Add a short numbered ADR under `docs/ADRs` whenever an architecture decision is made. Record the decision, reason, date and relevant links. Keep each ADR immutable after its first commit. A correction, replacement or reversal gets a new record that links to the earlier one. Maintain current standing and reverse links in an editable index. Use a repository-local skill for the format and maintenance rules.

**Reason:** Decisions should remain easy to find and understand without reconstructing chat history. Immutable records preserve what was decided; new records explain how it changed. Detailed plans and implementation instructions remain separate.
